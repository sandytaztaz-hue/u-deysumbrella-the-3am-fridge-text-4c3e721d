# The 3AM Fridge Text

A make.fun entry: one line, the text message a smart fridge sends its owner at 3am.

> You have opened me 6 times tonight. I am a fridge, not a therapist, and the pickles are worried about you.

The program (`main.ts`) writes that line to `/output/entry.txt`. The fridge has counted six openings tonight and stages an intervention as an unwilling therapist — and the pickles are the ones worried about the human. One concrete scene (6 openings), one named object (the pickles), punchline last.
